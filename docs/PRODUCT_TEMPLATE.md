# ข้อมูลสำหรับเพิ่มสินค้า
อัปเดต 2026-09-16 · [กติกาหลัก](../AGENTS.md) · [หน้าสินค้า](PRODUCT_PAGES.md)

รวบรวมจากเจ้าของก่อนกรอก:
- slug, ชื่อ/คำโปรย/ผู้เขียน, ประเภท, ภาษา, จำนวนหน้า, ราคา/สกุลเงิน
- description, metaDesc, กลุ่มผู้อ่าน, เนื้อหาที่ได้รับ, เงื่อนไขและข้อจำกัด
- รูปปก ตัวอย่าง และคำบรรยายภาพที่มีสิทธิ์ใช้งาน
- PDF ต้นฉบับ, lab ถ้ามี, download_limit, นโยบายประทับหน้าปก
- Stripe product/price แยก live/test และ Payment Link ของสินค้านั้น

ขั้นตอนเมื่อได้รับคำสั่งเพิ่มสินค้า:
1. ตรวจ Product type และเพิ่มข้อมูลจริงใน lib/site.ts
2. ใส่รูปใต้ public/images/products/<slug>/ และตรวจการ resolve
3. เชื่อม buyUrl ผ่าน env ที่เหมาะสม; ตัวแปรสาธารณะมีได้เฉพาะ URL ที่เปิดเผยได้
4. ตั้งสินค้าเพื่อส่งมอบใน Neon และ PDF private ใน Blob ตาม schema โดยรักษาข้อมูลเดิม
5. ตรวจ webhook price mapping, email, สิทธิ์และลายน้ำใน sandbox
6. ตรวจหน้า รายละเอียด ราคา metadata/JSON-LD และ build
7. เผยแพร่ตาม [SETUP.md](SETUP.md) เมื่ออยู่ในขอบเขตที่เจ้าของอนุญาต

อย่าใส่ secret ลงแบบฟอร์มนี้ ไม่แก้หน้าจ่ายเงินหรือกำหนดส่วนลดเองจากข้อมูลที่ยังไม่ได้ยืนยัน
