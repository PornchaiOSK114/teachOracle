### ขั้นที่ 1 — เตรียมรูปภาพ

สร้างโฟลเดอร์ `public/images/products/<slug>/` แล้ววางไฟล์:

| ไฟล์ | คืออะไร | ขนาดที่แนะนำ |
| :--- | :--- | :--- |
| `cover.jpg` | ปกหนังสือ | กว้าง ~1024 px, JPEG คุณภาพ 88 |
| `toc-01.png`, `toc-02.png` … | หน้าสารบัญ | กว้าง ~1100 px, PNG |
| `author.png` | หน้าเกี่ยวกับผู้เขียน | กว้าง ~1100 px, PNG |
| `sample-01.png` … `sample-05.png` | ตัวอย่างเนื้อหา | กว้าง ~1100 px, PNG |

- นามสกุลใช้ `.png` / `.jpg` / `.jpeg` / `.webp` ก็ได้ ระบบหาให้เอง **ไม่ต้องแก้โค้ด**
- ยังไม่มีไฟล์ก็ทำขั้นต่อไปได้เลย หน้าจะขึ้นกล่อง placeholder แทน ไม่พัง
- ตั้งชื่อไฟล์เป็นภาษาอังกฤษพิมพ์เล็กเท่านั้น ห้ามมีเว้นวรรคหรือภาษาไทย

<details>
<summary>สคริปต์ Python ย่อ/บีบอัดรูปให้อัตโนมัติ (ถ้ามีรูปเยอะ)</summary>

```python
# pip install pillow
from PIL import Image
import glob, os

SRC = 'รูปต้นฉบับ'     # โฟลเดอร์รูปดิบ
DST = 'พร้อมใช้'        # โฟลเดอร์ผลลัพธ์
os.makedirs(DST, exist_ok=True)

for f in glob.glob(f'{SRC}/*.png') + glob.glob(f'{SRC}/*.jpg'):
    name = os.path.basename(f)
    im = Image.open(f).convert('RGB')

    if name.startswith('cover'):
        # ปก = ภาพถ่าย → JPEG
        if im.width > 1024:
            im = im.resize((1024, round(im.height * 1024 / im.width)), Image.LANCZOS)
        im.save(f'{DST}/cover.jpg', 'JPEG', quality=88, optimize=True, progressive=True)
    else:
        # หน้าหนังสือ = ตัวอักษรบนพื้นขาว → PNG palette 64 สี (เล็กลง ~70%)
        if im.width > 1100:
            im = im.resize((1100, round(im.height * 1100 / im.width)), Image.LANCZOS)
        im.quantize(colors=64, dither=Image.FLOYDSTEINBERG).save(
            f'{DST}/{os.path.splitext(name)[0]}.png', 'PNG', optimize=True)

    print(name, 'เสร็จ')
```

</details>

### ขั้นที่ 2 — เพิ่มข้อมูลใน `lib/site.ts`

เปิดไฟล์ `lib/site.ts` หา `export const products` แล้ว **เติม object ใหม่ต่อท้าย array**
(อย่าลบของเดิม อย่าลืมจุลภาค `,` คั่นระหว่าง object)

```ts
  {
    slug: 'ใส่-slug-ที่นี่',
    title: 'ชื่อหนังสือ',
    subtitle: 'คำโปรยใต้ชื่อ',
    kind: 'E-Book (ไฟล์ PDF)',
    kindShort: 'E-Book · PDF',
    authorName: `${author.name} (${author.nickname})`,
    price: 0,                       // ← ใส่ราคาเป็นตัวเลขล้วน
    currency: 'THB',
    pages: 0,                       // ← จำนวนหน้า
    language: 'ไทย',
    deliverables: ['ไฟล์ PDF xxx หน้า', 'ของแถม (ถ้ามี)'],
    imageDir: '/images/products/ใส่-slug-ที่นี่',
    coverFile: 'cover',
    cardDesc: 'คำโปรยสั้นบนการ์ด',
    metaDesc: 'คำอธิบายสำหรับ Google 2-3 บรรทัด ใส่คำค้นสำคัญ',

    sections: [
      // ── ย่อหน้าธรรมดา ──
      {
        kind: 'paragraphs',
        heading: 'หัวข้อ',           // ลบบรรทัดนี้ถ้าไม่อยากมีหัวข้อ
        items: [
          'ย่อหน้าแรก',
          'ย่อหน้าที่สอง',
        ],
      },

      // ── รายการหัวข้อย่อย ──
      {
        kind: 'bullets',
        heading: 'หัวข้อ',           // ใส่ '' ถ้าไม่อยากมีหัวข้อ
        items: [
          'ข้อแรก',
          'ข้อที่สอง',
        ],
      },

      // ── รายการแบบ "สิ่งที่ไม่มีในเล่ม" (เครื่องหมาย ✕) ──
      {
        kind: 'bullets',
        heading: 'ขอบเขตของเล่มนี้',
        deny: true,
        items: [
          'เรื่องที่ไม่ได้อยู่ในเล่ม',
        ],
      },

      // ── กล่องเน้นข้อความ ──
      {
        kind: 'note',
        heading: 'หัวข้อกล่อง',       // ลบบรรทัดนี้ได้ถ้าไม่ต้องการ
        text: 'ข้อความในกล่องเน้น',
      },
    ],

    samples: [
      { group: 'สารบัญ',          file: 'toc-01',    alt: 'สารบัญ หน้า i' },
      { group: 'สารบัญ',          file: 'toc-02',    alt: 'สารบัญ หน้า ii' },
      { group: 'เกี่ยวกับผู้เขียน', file: 'author',    alt: 'หน้าเกี่ยวกับผู้เขียน' },
      { group: 'ตัวอย่างเนื้อหา',  file: 'sample-01', alt: 'ตัวอย่างเนื้อหา หน้า 1' },
    ],

    buyUrl: process.env.NEXT_PUBLIC_STRIPE_LINK_XXXX ?? '',
  },
```

**กฎที่ห้ามพลาด**

| กฎ | เหตุผล |
| :--- | :--- |
| `slug` ต้องตรงกับชื่อโฟลเดอร์รูปเป๊ะ ๆ | ไม่งั้นรูปไม่ขึ้น |
| `price` เป็นตัวเลขล้วน ไม่ใส่ `฿` `,` หรือเครื่องหมายคำพูด | ใช้คำนวณและใส่ใน JSON-LD |
| `file` ใน `samples` **ห้ามใส่นามสกุล** | ระบบหานามสกุลให้เอง |
| ทุก `alt` ต้องมีข้อความจริง | จำเป็นต่อคนตาบอดและ SEO |
| ตัวแปร env ต้องขึ้นต้น `NEXT_PUBLIC_` | ไม่งั้นฝั่งเบราว์เซอร์อ่านไม่เห็น |
| **ห้ามใส่ข้อมูลที่ยังไม่ยืนยัน** (ราคา สถิติ รีวิว) | กติกาข้อแรกของโปรเจกต์ใน `AGENTS.md` |

### ขั้นที่ 5 — ขึ้นเว็บจริง

สร้างไฟล์ `.bat` (UTF-8 with BOM + CRLF) ในรากโปรเจกต์ แล้วดับเบิลคลิก

```bat
@echo off
chcp 65001 >nul
cd /d "%~dp0"

if exist ".git\index.lock" del /f ".git\index.lock"

git add lib/site.ts
git add public/images/products
git add .env.example

echo.
echo --- ไฟล์ที่จะถูก commit ---
git diff --cached --name-status
echo ---------------------------
echo.
pause

git commit -m "feat(products): เพิ่มสินค้า <ชื่อหนังสือ>"
git push origin main

echo.
echo [OK] push เรียบร้อย - Vercel กำลัง build อัตโนมัติ
pause
```

> ⚠️ **ห้ามใช้ `git add -A`** — โฟลเดอร์นี้มักมีการแก้ค้างที่ไม่เกี่ยวกับงานนี้
> ให้ระบุ path ทีละไฟล์เสมอ และดูรายการที่สคริปต์พิมพ์ออกมาก่อนกด Enter

หลัง push แล้วรอ Vercel build 1-2 นาที → เปิด `https://teedba.com/products`

## ภาคผนวก — เพิ่มสินค้าในโซน "กำลังจะมา" (ยังไม่ขาย)

ถ้ายังไม่พร้อมขาย แค่อยากประกาศไว้ ให้เติมใน `upcomingProducts` แทน — ไม่ต้องมีหน้า detail

```ts
export const upcomingProducts = [
  {
    icon: '📗',                              // อีโมจิอะไรก็ได้
    title: 'ชื่อผลิตภัณฑ์',
    desc: 'คำอธิบายสั้น 1-2 บรรทัด',
  },
  // ... ของเดิม
] as const;
```

พอพร้อมขายจริงค่อยย้ายมาทำเป็น `products` เต็มรูปแบบตามขั้นตอนข้างบน
