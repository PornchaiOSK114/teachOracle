## ขั้นที่ 3 ติดตั้งสคริปต์ส่งไฟล์

1. เปิดชีตที่เพิ่งสร้าง ไปที่เมนู **Extensions › Apps Script**
2. ลบโค้ดตัวอย่างทิ้งให้หมด แล้ววางเนื้อหาจากไฟล์ [`apps-script/Code.gs`](./apps-script/Code.gs) ลงไปทั้งไฟล์
3. กด Save
4. เลือกฟังก์ชัน `setupOnce` จาก dropdown ด้านบน แล้วกด **Run**
5. ครั้งแรกจะขึ้นหน้าขออนุญาต กด **Advanced › Go to ... (unsafe) › Allow**

ที่ขึ้นคำว่า unsafe เพราะเป็นสคริปต์ที่เราเขียนเอง ไม่ได้ผ่านการรีวิวของ Google ไม่ใช่เรื่องผิดปกติ

**สคริปต์จะจัดการให้อัตโนมัติ**

- สร้างคอลัมน์ `อนุมัติ`, `สถานะส่ง`, `เวลาที่ส่ง` ต่อท้ายตาราง
- ติดตั้ง trigger สามตัว: รับออเดอร์ใหม่, ตรวจการพิมพ์ OK, และปิดฟอร์มอัตโนมัติเมื่อถึง 31 ส.ค. 23:59
- เพิ่มเมนู **ส่งหนังสือ** ในชีต

**ไฟล์ที่จะแนบไปกับอีเมล** สคริปต์ดึงทุกไฟล์จากโฟลเดอร์ Drive นี้

```
https://drive.google.com/drive/folders/1-Mi2EuJD3dC9pA2ue2c_xdbm9sowKFfx
```

วางไฟล์ PDF กับ ZIP ไว้ในนั้น ห้ามวางไฟล์อื่นปน เพราะมันจะถูกแนบไปด้วยทั้งหมด

## ขั้นที่ 4 ทดสอบก่อนเปิดขาย

ทำให้ครบทุกข้อ อย่าข้าม

- [ ] เมนู **ส่งหนังสือ › ส่งอีเมลทดสอบมาหาตัวเอง** แล้วเปิดดูว่าไฟล์แนบครบและเปิดได้จริง
- [ ] กรอกฟอร์มด้วยรหัสผิด เช่น `TTC123` ต้องกดถัดไปไม่ผ่าน และขึ้นข้อความที่เราเขียนไว้
- [ ] กรอกฟอร์มด้วยรหัสถูก ใช้อีเมลตัวเอง แล้วกด Submit จริง
- [ ] เช็คว่าได้อีเมลตอบรับ และได้อีเมลแจ้งเตือน `[ออเดอร์ใหม่]`
- [ ] ไปที่ชีต พิมพ์ `OK` ในคอลัมน์อนุมัติของแถวทดสอบ
- [ ] ภายในไม่กี่วินาที ต้องได้อีเมลพร้อมไฟล์แนบ และคอลัมน์สถานะส่งขึ้นว่า `ส่งแล้ว`
- [ ] พิมพ์ `OK` ซ้ำอีกรอบ ต้อง**ไม่**ส่งซ้ำ
- [ ] ลบแถวทดสอบทิ้งก่อนเปิดขายจริง

## ขั้นที่ 5 เอาลิงก์ฟอร์มขึ้นเว็บ

1. ในฟอร์มกด **Send › ไอคอนลิงก์ › Copy** จะได้ลิงก์แบบ `https://forms.gle/xxxxx`
2. ไปที่ **Vercel › โปรเจกต์ › Settings › Environment Variables**
3. เพิ่มตัวแปร

   ```
   NEXT_PUBLIC_ALUMNI_FORM_URL = https://forms.gle/xxxxx
   ```

4. กด **Redeploy**

ตัวแปรขึ้นต้น `NEXT_PUBLIC_` ถูกฝังลง bundle ตอน build จึงต้อง redeploy ทุกครั้งที่แก้ค่า แค่ save เฉย ๆ ไม่พอ

**ถ้ายังไม่ได้ตั้งค่า** กล่องโปรจะยังขึ้นบนเว็บ แต่ปุ่มจะเป็นสถานะ "กำลังเปิดรับเร็ว ๆ นี้" กดไม่ได้

**หลัง 31 ส.ค. 23:59** กล่องโปรจะหายไปจากหน้าเว็บเองภายใน 15 นาที และฟอร์มจะปิดรับเอง ไม่ต้องกลับมาแก้อะไร

## สิ่งที่ระบบนี้ยังไม่ทำ

พูดตรง ๆ ไว้ก่อน จะได้ไม่คาดหวังผิด

- **ไม่ได้ตรวจสลิปอัตโนมัติ** คุณต้องเปิดแอปธนาคารเทียบยอดเอง สำหรับพรีออเดอร์ที่มีไม่กี่สิบรายถือว่าคุ้มกว่าลงทุนทำระบบ
- **ไม่จำกัดจำนวนดาวน์โหลด** เพราะส่งเป็นไฟล์แนบ ลูกค้าเก็บไฟล์ไว้ได้เลย ซึ่งตกลงกันไว้แล้วว่าไม่เป็นไรเพราะเป็นราคาพิเศษ
- **ไม่ได้ประทับชื่อผู้ซื้อลงใน PDF** ถ้าอยากได้ทีหลัง ทำเพิ่มได้ ไม่ต้องรื้อระบบเดิม
- **รหัส `TTC490` จะหลุดแน่นอน** ถ้าใครส่งต่อกัน จึงต้องมีวันปิดรับ ซึ่งตั้งไว้แล้วที่ 31 ส.ค.
