## 2. 🔴 ระเบิดเวลาที่ค้างอยู่ใน working tree — อ่านก่อนแตะ git

`git status` ตอนนี้มีของค้าง 4 ไฟล์ **ที่ยังไม่ได้ commit และห้าม commit มั่ว**

| ไฟล์ | สภาพ | ประเมิน |
|---|---|---|
| `tsconfig.json` | `"jsx": "preserve"` → **`"jsx": "react-jsx"`** + จัดฟอร์แมตใหม่ + เพิ่ม `.next/dev/types/**/*.ts` | ⚠️ **อันตรายสุด** — Next.js ต้องการ `preserve` ถ้า commit ไปโดยไม่ทดสอบ build อาจพัง ต้องรัน `next build` ผ่านก่อนเท่านั้น |
| `content/articles/ora-01555-snapshot-too-old.mdx` | **ถูกลบไป 372 บรรทัด** | ⚠️ บทความนี้ยัง live อยู่บนเว็บ (commit ล่าสุดที่แตะคือ `8cadf93`) ถ้า commit การลบนี้ = บทความหายจากเว็บ **ต้องถามเจ้าของก่อนว่าตั้งใจลบไหม** |
| `content/articles/_example-thai-charset.mdx` | มีคำว่า `Markdown Preview Enhanced` หลุดเข้าไปกลางประโยค | พิมพ์หลุดจาก VS Code extension ควร revert ทิ้ง (ไฟล์นี้ `draft: true` ไม่ขึ้นเว็บ) |

### เริ่มด้วยการถามให้จบก่อนลงมือ (`docs/STRIPE_PLAN.md` §5)

3. ยอมเสียค่าธรรมเนียม Stripe แทน PromptPay ตรงที่ 0% ไหม

## 4. วิธีทำงานที่ต้องใช้กับ repo นี้ (บทเรียนราคาแพงจากเซสชันก่อน)

1. **push สำเร็จ ≠ เว็บเปลี่ยน** — เคย push ผ่านแต่ Vercel build ERROR เพราะลืม stage ไฟล์ที่อ้างถึงกัน ต้องเช็ค deployment `state` เสมอ แล้วดึง HTML จริงมาดู
2. **"Redeploy" ของ Vercel ไม่ดึงโค้ดใหม่** — มัน build commit เดิมซ้ำ ต้อง push commit ใหม่เท่านั้น
3. **`tsc --noEmit` จับไม่หมด** — โค้ดที่ import `node:fs` แล้วหลุดเข้า `'use client'` มีแต่ `next build` เท่านั้นที่จับได้ ต้องรัน `next build` ก่อนส่งเสมอ
4. **`params` ใน Next 16 เป็น Promise** ต้อง `await`
5. **ไฟล์ `.bat` ต้องเป็น ASCII ล้วน CRLF ไม่มี BOM** — cmd.exe นับตำแหน่งไฟล์เป็นไบต์แต่นับความยาวบรรทัดเป็นตัวอักษร ภาษาไทย 3 ไบต์/ตัว ทำให้ cmd อ่านต่อกลางบรรทัดแล้วพัง `chcp 65001` ไม่ช่วย ตรวจด้วย `LC_ALL=C grep -P '[^\x00-\x7F\r]'`
6. **`device_bash` ลบไฟล์ไม่ได้** ให้ `mv` เข้า `_to_delete/` แล้วบอกเจ้าของไปลบเอง
7. **`device_bash` ออกอินเทอร์เน็ตไม่ได้** (proxy 403) — `git fetch/push` ต้องให้เจ้าของรันบน Windows เอง มี `push-only.bat` และ `push.bat` เตรียมไว้ให้แล้วในโฟลเดอร์เว็บ
8. **`SendUserFile` อย่างเดียวไม่ทำให้ไฟล์ไปอยู่ในโฟลเดอร์เว็บ** ต้องตามด้วย `device_commit_files` แล้วเทียบ SHA-256 สองฝั่ง

## 6. กติกาประจำที่ห้ามลืม

- **ห้ามกุข้อมูล** — ราคา สถิติ ชื่อลูกค้า รีวิว ถ้าไม่มีข้อมูลจริงให้ถาม ห้ามเดา ข้อมูลจริงอยู่ใน `lib/site.ts` เท่านั้น
- **ห้ามใส่ภาษาไทยในโค้ดถ้าไม่จำเป็น** (คำสั่งตรงจากเจ้าของ หลัง `.bat` พังเพราะภาษาไทย) — คอมเมนต์ในไฟล์ `.tsx`/`.ts` เป็นไทยได้ แต่ `.bat`/shell/ชื่อไฟล์ต้อง ASCII
- **ถามก่อนลงมือ** เจ้าของชอบเห็นแผนก่อน เขาเคยสั่งว่า "อย่าเพิ่งทำจริง จนกว่าฉันจะยืนยัน"
- URL ที่พิมพ์ในหนังสือไปแล้ว **ห้ามเปลี่ยน ห้ามลบตลอดกาล**: `/lab`, `/en`, `/en/lab` (มีคอมเมนต์เตือนไว้หัวไฟล์แต่ละหน้าแล้ว)
- เจ้าของสื่อสารเป็นภาษาไทย ตอบเป็นภาษาไทย
