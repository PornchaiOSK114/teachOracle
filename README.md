# 📚 อาจารย์ตี๋ที่สอน Oracle — คู่มือโครงสร้างโปรเจ็ค

## 📂 หน้าที่ของแต่ละโฟลเดอร์

### 1. `app/` — หน้าเว็บและ routing

Next.js ใช้ **ชื่อโฟลเดอร์เป็น URL** โดยตรง — โฟลเดอร์ `app/courses/` = `teedba.com/courses`
ส่วน `[slug]` คือส่วนที่เปลี่ยนได้ตามชื่อไฟล์บทความ

ไฟล์พิเศษที่ Next รู้จักเอง: `layout.tsx` (โครงร่วม) · `page.tsx` (เนื้อหาหน้า) ·
`not-found.tsx` (404) · `route.ts` (API ที่ไม่ใช่หน้าเว็บ)

### 2. `components/` — ชิ้นส่วน UI

แยกออกมาเพื่อใช้ซ้ำหลายหน้า แก้ที่เดียวเปลี่ยนทุกที่
โฟลเดอร์ย่อย `mdx/` พิเศษหน่อย — เป็น component ที่**เรียกใช้จากในบทความได้** (ดู `WRITING_GUIDE.md`)

### 3. `content/` — คลังบทความ

ทำหน้าที่เป็น "ฐานข้อมูล" ของเว็บ แต่เป็นไฟล์ธรรมดา ไม่ต้องมี server ฐานข้อมูล
ข้อดี: แก้ด้วย editor อะไรก็ได้ · เก็บประวัติผ่าน Git · ย้ายเว็บได้ทันทีโดยเนื้อหาไม่หาย

### 4. `lib/` — ตรรกะเบื้องหลัง

**`site.ts` คือไฟล์ที่คุณจะแก้บ่อยที่สุด** — ข้อมูลหลักสูตร ช่องทางติดต่อ ผลงานเขียน
ตัวเลขบนหน้าแรก อยู่ที่นี่ทั้งหมด แก้ครั้งเดียวเปลี่ยนทั้งเว็บ

> ⚠️ `content.ts` ใช้ระบบไฟล์ (`node:fs`) จึงรันได้เฉพาะฝั่งเซิร์ฟเวอร์
> ฟังก์ชันที่ฝั่งเบราว์เซอร์ต้องใช้ด้วยให้แยกไว้ที่ `format.ts` (เหตุผลเต็มใน `AGENTS.md` ข้อ H)

- 🌗 **สลับโหมดสว่าง/มืด** จำค่าไว้ และไม่กระพริบตอนเปิดหน้า
- 📱 **ดูได้ทุกจอ** ตั้งแต่มือถือเล็กถึงจอใหญ่ ปุ่มทุกอันแตะง่ายบนมือถือ (สูง ≥44px)
- 🔍 **ค้นหา + กรองหมวด** บทความแบบทันที ไม่ต้องโหลดหน้าใหม่
- 📑 **สารบัญอัตโนมัติ** ในบทความที่มีหัวข้อตั้งแต่ 2 อัน

- ✍️ เขียน Markdown ธรรมดา ไม่ต้องรู้โค้ด
- 📝 ระบบฉบับร่าง — เขียนค้างได้ไม่มีใครเห็น
- 🎬 ฝัง YouTube/Vimeo/SoundCloud/MP3 ด้วยคำสั่งบรรทัดเดียว

- 🔎 **SEO ครบ** — metadata ต่อหน้า, canonical, sitemap, RSS, Open Graph

## ⚙️ Environment Variables

ตั้งที่ **Vercel › Settings › Environment Variables**

| ตัวแปร | จำเป็น | ความหมาย |
| :--- | :---: | :--- |
| `NEXT_PUBLIC_CF_BEACON_TOKEN` | – | token นับสถิติ Cloudflare (ตั้งเฉพาะ Production) |

| `NEXT_PUBLIC_SITE_URL` | – | ตั้งเฉพาะเมื่อจะย้ายโดเมน (ค่าเริ่มต้น `https://teedba.com` อยู่ใน `lib/site.ts` แล้ว) |
